# FD Nail Planner

Offline planning page for Fassier-Duval telescopic nailing (osteogenesis imperfecta / fragile bone disease): osteotomy simulation, canal diameter to nail size, lengths.

- Films stay in the browser on the computer that opens them. Nothing is uploaded.
- Implant figures are from the maker's surgical technique guide (FD-ST-EN Rev M, Jan 2024).
- A planning aid for a trained surgeon; check every figure against the film and the set in theatre.
